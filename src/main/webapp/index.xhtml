Bienvenido a PrimeNG JSF Showcase

Demostración de componentes JSF con PrimeFaces y PrimeFlex

Una aplicación web Java desarrollada siguiendo las mejores prácticas

Formularios

Inputs, validaciones, file uploads y más. Explora los componentes de entrada de datos con validaciones del lado del cliente y servidor.

Tablas de Datos

DataTable con paginación, ordenamiento, filtrado y exportación. Componentes poderosos para visualización de datos.

Gráficos

Visualización de datos con Charts.js integrado. Diferentes tipos de gráficos: línea, barra, pie, etc.

Paneles

Organiza tu contenido con Panels, Accordions, TabViews. Componentes para estructurar interfaces complejas.

Mensajes

Sistema de notificaciones con Messages y Growl. Feedback visual para operaciones del usuario.

Y mucho más...

PrimeFaces incluye más de 100 componentes listos para usar. Descubre todos navegando por el menú lateral.

Backend

  • Java 11 - Lenguaje de programación
  • JSF 2.3 - JavaServer Faces framework
  • CDI - Contexts and Dependency Injection
  • Maven - Gestión de dependencias

Frontend

  • PrimeFaces 13 - Componentes UI
  • PrimeFlex 3 - CSS Grid System
  • Font Awesome - Iconos
  • Chart.js - Visualización de datos
  • Arquitectura en capas - Separación clara entre vista, controlador y modelo
  • CDI Beans - Gestión de dependencias con inyección
  • Templates reutilizables - Facelets para mantener DRY
  • Validaciones - Del lado cliente y servidor
  • Manejo de errores - Páginas de error personalizadas
  • Responsive Design - PrimeFlex para adaptabilidad móvil
  • Performance - AJAX parcial, lazy loading, caching
  • Seguridad - Configuración de sesiones, CSRF protection
  • Código documentado - Comentarios explicativos en todo el código
