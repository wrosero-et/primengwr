Demostración de Gráficos

Visualización de datos con Chart.js integrado en PrimeFaces

Ideal para mostrar tendencias a lo largo del tiempo. Compara múltiples series de datos fácilmente.
Perfecto para comparar diferentes categorías. Los valores se muestran claramente en cada barra.
Excelente para mostrar proporciones y porcentajes. Visualiza la distribución de un total.

Características

  • Interactivos: Tooltips al pasar el mouse
  • Responsive: Se adaptan al tamaño de pantalla
  • Animados: Transiciones suaves al cargar
  • Personalizables: Colores, leyendas, ejes
  • Exportables: Se pueden guardar como imagen

Tipos Disponibles

PrimeFaces soporta múltiples tipos de gráficos:

  • Line (Líneas)
  • Bar (Barras)
  • Pie (Circular)
  • Donut (Dona)
  • Radar
  • Polar Area
  • Bubble (Burbujas)
  • Scatter (Dispersión)

Casos de Uso

  • Dashboards: KPIs y métricas de negocio
  • Análisis: Tendencias y patrones
  • Reportes: Visualización de informes
  • Monitoreo: Métricas en tiempo real

Managed Bean (Java)

@Named
@ViewScoped
public class ChartBean implements Serializable {
    private LineChartModel lineModel;
    
    @PostConstruct
    public void init() {
        lineModel = new LineChartModel();
        
        LineChartSeries series = new LineChartSeries();
        series.setLabel("Ventas 2024");
        series.set("Ene", 75);
        series.set("Feb", 69);
        series.set("Mar", 90);
        
        lineModel.addSeries(series);
        lineModel.setTitle("Ventas Mensuales");
    }
    
    // Getters y setters...
}

Vista XHTML

<p:chart type="line" 
         model="#{chartBean.lineModel}" 
         style="height:300px"
         responsive="true"/>
  • Simplicidad: No sobrecargues los gráficos con demasiados datos
  • Colores: Usa colores consistentes y accesibles
  • Leyendas: Siempre incluye leyendas claras
  • Ejes: Etiqueta los ejes con unidades claras
  • Responsive: Asegúrate que funcionen en móviles
  • Performance: Limita los puntos de datos para grandes conjuntos
  • Actualización: Usa AJAX para actualizar sin recargar
  • Exportación: Permite descargar los datos
